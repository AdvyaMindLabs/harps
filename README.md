# HARPS — Advaya Mindlabs Community

HARPS is a community platform initiative under Advaya Mindlabs. This initial release is a static landing-page prototype, not a production member platform.

Local: npm install, then npm run dev.
Checks: npm run typecheck, npm run build, npm test.
Cloudflare Pages build command: npm run build; output directory: dist.

Privacy: This prototype collects no member data and has no authentication. Do not launch registration, member profiles, or AI matching until consent, access controls, deletion, moderation, and security testing are implemented.
